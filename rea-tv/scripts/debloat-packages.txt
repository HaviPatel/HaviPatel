# REA TV debloat list for Amazon Fire TV (Fire OS 6/7/8).
#
# Format: tier|package|what it is
#   1 = ads, telemetry, promos (safe for everyone)
#   2 = Amazon apps you may not use (Photos, Music, Freevee, Kids, Prime Video...)
#   3 = advanced: Alexa voice, system updates, push messaging, Appstore
#
# Packages are only ever disabled with `pm disable-user --user 0`, which is fully reversible
# (scripts/rea.sh restore, or a factory reset). Packages that are missing on your build are skipped;
# protected ones simply fail and are reported. Amazon's launcher, setup, settings and core
# services are deliberately absent: the scripts refuse to touch them.

1|com.amazon.device.crashmanager|Crash report uploader
1|com.amazon.client.metrics|Usage metrics client
1|com.amazon.client.metrics.api|Usage metrics API
1|com.amazon.device.metrics|Device metrics (protected on some builds)
1|com.amazon.dp.logger|Diagnostics logger
1|com.amazon.kso|Sponsored content / special offers
1|com.amazon.shoptv.client|Amazon Shopping on TV
1|com.amazon.storm.lightning.tutorial|Fire TV tutorial videos
1|com.amazon.tv.releasenotes|"What's new" release notes
1|com.amazon.ags.app|Amazon GameCircle

2|com.amazon.bueller.photos|Amazon Photos (also powers the Amazon Photos screensaver)
2|com.amazon.bueller.music|Amazon Music
2|com.amazon.imdb.tv.android.app|Freevee
2|com.amazon.tv.livetv|Live TV guide integration
2|com.amazon.firebat|Amazon Kids+
2|com.amazon.avod|Prime Video (legacy)
2|com.amazon.amazonvideo.livingroom|Prime Video
2|com.amazon.wcast.sink|Display mirroring (Miracast)
2|com.amazon.tv.legal.notices|Legal notices viewer

3|com.amazon.vizzini|Alexa voice (voice search stops working)
3|com.amazon.alexa.externalmediaplayer.fireos|Alexa media playback integration
3|com.amazon.tv.alexaalerts|Alexa alerts and reminders
3|com.amazon.device.software.ota|System update downloader (you stop getting security updates)
3|com.amazon.device.software.ota.override|System update override
3|com.amazon.tv.forcedotaupdater.v2|Forced update prompt
3|com.amazon.tcomm|Amazon device messaging (may break the Fire TV phone remote)
3|com.amazon.device.messaging|Push messaging (ADM), some apps need it for notifications
3|com.amazon.venezia|Amazon Appstore (apps stop auto-updating)
3|com.ivona.tts.oem|IVONA voices (needed by VoiceView screen reader)
